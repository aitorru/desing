# Dot 2

Dot 2 es la versión sobria de Dot: la misma rejilla y los mismos componentes, pero con papel en
vez de vidrio, un solo color de acento y patrones quietos en lugar de cintas que se mueven. Es
la que quieres para un informe semanal, un post-mortem o una consola que alguien va a mirar con
sueño.

Se activa con un atributo, junto al tema, y no rompe nada de v1:

```html
<html data-pt-theme="light" data-pt-version="2">
```

## Cuándo usar cuál

- **Dot 1:** portadas, demos, la pantalla de un lanzamiento. Donde un poco de color en
  movimiento suma.
- **Dot 2:** todo lo que se lee con calma o se imprime: informes, post-mortems, paneles de
  estado, revisiones de coste. En la duda, esta.

## Qué cambia

| | Dot 1 | Dot 2 |
| --- | --- | --- |
| **Puntos** | Textura: cintas aleatorias que fluyen (`DotField`) | **Patrón**: seis motivos geométricos, quietos y anclados (`DotPattern`) |
| **Color** | Degradado violeta → magenta → coral | **Un sello**: un único acento sólido por pantalla |
| **Superficie** | Vidrio esmerilado con brillo | **Papel y filete**: panel casi opaco, borde de 1 px, sombra corta |
| **Forma** | Radios 8 / 14 / 22 / 32 y botones píldora | **Todo en la rejilla**: 4 / 8 / 12 / 16 y controles rectos |
| **Paleta** | Punto (lavanda) | **Siena** de serie: papel hueso, tinta café, terracota |

En la práctica:

- **Un patrón por superficie**, en una esquina o detrás de una cifra. Sale siempre igual, así
  que la captura del informe de esta semana se parece a la de la anterior.
- **Un solo acento.** El botón principal, un anillo del patrón, un folio. Si hay dos en
  pantalla, sobra uno; el rojo queda libre para lo que está caído.
- **La lámina de tinta** (`GlassCard tone="bloom"`) es la superficie oscura para la cifra que
  importa: la severidad del incidente, el error budget que queda.
- **Orden de informe**: folios (`.pt-folio`, `SectionHeader index="01"`), filetes (`.pt-rule`)
  y cifras en una fila pautada, no en cuatro tarjetas.
- **Quieto por defecto.** Como mucho, `motion="breathe"` (un ciclo de siete segundos).
  `DotField` sigue ahí para la portada.

```tsx
<GlassCard backdrop={<DotPattern motif="rings" anchor="top-right" cols={22} rows={14} highlight={2} />}>
  …
</GlassCard>
```

| Prop | Qué hace |
| --- | --- |
| `motif` | `grid` · `fade` · `rings` · `orb` · `wave` · `diagonal` |
| `cols`, `rows` | Tamaño en puntos. Sin ellos, rellena el contenedor posicionado |
| `anchor` | Lo fija a una esquina, un borde o el centro; el motivo crece desde ahí (`origin` lo cambia) |
| `highlight` | La banda (anillo, cresta, diagonal…) que lleva el sello. `null` = ninguna |
| `tone`, `intensity` | `ink` / `accent` / `current` y opacidad: un patrón se intuye, no se lee |
| `period`, `falloff` | Separación entre bandas y cuánto se apaga al alejarse del origen |

A diferencia de `DotField`, **lee los roles del tema**: el mismo patrón sirve en cualquier
paleta, en Mist y en Ink, sin una variante de color propia.

## Componentes de operaciones

Todos hechos de puntos y filetes, y todos funcionan también en v1:

| Componente | Para qué |
| --- | --- |
| `Status` | Un estado como punto + palabra: correcto, degradado, caído, en curso, sin datos. La forma del punto acompaña al color, para quien no distingue el rojo del verde |
| `DataTable` | Tabla pautada: cabeceras en versalitas, cifras en mono, orden por columna, fila seleccionada |
| `Diagram` | Cajas y conectores de puntos sobre una rejilla: arquitectura, caminos de petición, dependencias |
| `Pipeline` | Una ejecución como línea de puntos: compilar → probar → desplegar |
| `KeyValue` | Metadatos con guía de puntos (commit, región, imagen) |
| `CodeBlock` · `LogView` | Configuración y registros en IBM Plex Mono, sin colores de sintaxis |
| `DotUptime` | Historial como tira de puntos: solo las incidencias llevan color |

Están juntas en **Pages › Dot 2 › Operaciones**.

## Modo noche y OLED

Para la guardia de noche hay un tercer tema, `oled`: Ink sobre negro puro (`#000`). Sin
sombras (sobre negro no se ven), las superficies suben un paso de tinta y el filete lleva la
estructura; el texto baja un punto de blanco para no deslumbrar a las tres de la mañana.

```tsx
const { preference, setPreference } = useTheme({ night: "oled" });
<ThemeSwitch value={preference} onChange={setPreference} />
```

`useTheme()` recuerda la elección (`localStorage`), sigue al sistema mientras la preferencia
sea `system` y mantiene `data-pt-theme` en `<html>`. `themeInitScript()` devuelve el script
en línea para el `<head>` que evita el destello blanco al cargar.

## Qué no cambia

- La rejilla de 4 px y los puntos cada 8.
- Instrument Serif para decir, Inter Tight para hacer.
- Los puntos como estado y como dato: `DotLoader`, `DotProgress`, `DotBars`, `DotDivider`.
- Mist, Ink y OLED, y las cinco paletas: en v2 cada una aporta su sello y su lámina.
- `prefers-reduced-motion`.
